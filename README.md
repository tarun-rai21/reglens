# RegLens

Regulatory change intelligence for Indian banks across Basel, RBI and FATF: versioned,
provision-level, verifiable.

> **Status:** early development. The repository is being bootstrapped; there is no runnable code yet.

## What it will do

- Ingest Basel (BIS), RBI and FATF publications as versioned documents, parsed down to
  individual provisions.
- Answer regulatory questions with citations to the exact provision and version, and abstain
  when the corpus does not support an answer.
- Track what changed between versions, and how material each change is.
